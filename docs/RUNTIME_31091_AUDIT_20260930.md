## 2026-09-30 compatibility runtime update

The compatibility build now bundles official production DLSS SR/RR/FG 310.9.1 and Streamline 2.14.1, plus matching DeepDVC and Vulkan low-latency helpers. `dist/runtime_versions.json` pins all 16 DLLs to the official SDK archive (SHA256 and sizes); CI verifies this inventory before packaging. The existing optional Neural Rendering plugin/runtime are retained separately at their previous versions: they are not part of this SDK upgrade.

All 16 new DLLs have valid NVIDIA Authenticode signatures. Static inspection finds one match each for the existing advertise/validate MFG patterns and 31 eligible kernel containers in the new DLSSG, matching the previous baseline. No MFG C++ patch was changed for this runtime update.
