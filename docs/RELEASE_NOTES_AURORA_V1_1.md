# OptiScaler Aurora v1.1 — 运行库更新与兼容性修复

本版更新 DLSS / Streamline 运行库，重点修复帧生成初始化、失败清理、资源访问及关闭过程中的问题。保留 Aurora 的 RTX 40 多帧生成路线和默认 `DualFeature=false`，不包含已停止开发的 RC3 一键安装器。

## 更新内容

- 集成官方 DLSS SR / RR / FG **310.9.1**、Streamline **2.14.1** 及必要配套文件。可选 Neural Rendering 仍使用原有 310.8 Runtime / 2.13 插件，不混称为 310.9.1。
- Runtime Sync 增加版本保护：保留游戏中较新的运行库、原生 Streamline 1.x 和无法安全识别的组，避免使用包内旧版本降级替换。
- 改善帧生成与 Reflex 状态检查，避免继续使用失配或未就绪的帧状态。
- 修复 NGX / 替换组件初始化失败被误当作成功、部分初始化后丢失清理责任、创建失败后的句柄处理及重复释放问题。已记录为未就绪的设备不再继续 Create / Evaluate，仍允许有明确所有权的清理。
- 加强多设备调用、初始化与关闭之间的互斥，以及共享对象完整构造后的发布；初始化前拒绝损坏的 Runtime 路径列表。
- 修复 HUD 处理失败后未恢复资源状态的问题；复制前检查尺寸、格式、采样及设备一致性，拒绝同对象 CPU 并发／重入，失败时跳过可选处理。修复部分构造失败后的资源清理与重试。
- 可选深度复制增加设备、描述符、自复制及 CPU 重入检查；准备失败时保留原始深度。
- Vulkan 耗时统计跳过未就绪／失败的查询结果，避免使用无效输出，并改善统计锁的异常释放。
- 吸收经过审查的上游旧 UE Runtime 路径、资源空值／格式和接口转发修复；改进私有 Streamline 绑定、增量格式检查与构建产物追踪。

## 验证范围与已知限制

发行构建要求完整 Windows DLL 编译、配置的兼容性专项检查、运行库版本／SHA256 清单及打包校验全部通过。CPU 故障注入和构建通过不等同于所有游戏／GPU 已验证。

用户已反馈《巫师3》RTX 4080 Laptop、DLSSG 310.9.1、6X 正常运行；本版没有追加读图、动态 MFG 切换和轻微闪烁的完整实机回归，不能承诺这些症状已经彻底消失。《绝区零》组件异常 11008 及文件消失反馈仍缺少对应日志，尚不能确认解决；原神、崩铁各类桥接环境也未全部验证。

HUD／深度资源不匹配时会跳过可选处理，尚不支持完整的跨设备／尺寸自动重建。GPU 提交完成、描述符复用和退役，以及外层初始化后段异常的全局回滚仍是后续工作。本版撤出尚未闭环的全局回滚、配套设备发布重排和 Vulkan 查询池复用实验；保留已完成的局部保护，不把这些实验宣称为正式功能。

本版未签名。下载本 Release 的 `.7z` 包及 `SHA256SUMS.txt`；保留现有配置和游戏原文件备份。旧 v1.0 Release 保持可用。Aurora 不自动修改全局驱动设置，也不提供反作弊绕过。
