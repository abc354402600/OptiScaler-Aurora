# 游戏兼容性与已知限制

**简体中文** | [English](COMPATIBILITY.en.md) · [返回首页](../README.md)

更新至 Aurora v1.1。这里区分历史实机反馈、本版代码验证和未解决问题；不把旧记录改写为新版本全量实测。

## 巫师3

2026-09-30 用户反馈 RTX 4080 Laptop、DLSSG 310.9.1、6X 正常运行。截图可确认 DLSSG 版本和倍率，但未直接显示已加载的 Streamline 版本。

- Proxy 使用 `dxgi.dll`；DX12 入口通常位于 `bin\x64_dx12`。
- 旧版游戏中原生 Streamline 1.5.6 的保护仍有效；新版按实际文件版本处理，不能把所有巫师3安装都固定判为 SL1。
- 旧版已验证的一条路线为：游戏使用 DLSS 超分、关闭原生 FG，Aurora 的 `FG Input → OptiFG (Upscaler)`、`FG Output → DLSSG`、`FG Nvngx Replacement → None (Real DLSSG)`。保存并完全重启，再进入场景启用 DLSSG 和选择倍率。这是旧配置参考，不要求新版已有正常路线的用户强行切换。
- 高倍率读图、动态 MFG／固定 6X 切换和轻微闪烁仍未完成全面实机回归。v1.1 有相关状态及生命周期保护，但不能据此宣称症状全部消失。

[旧版设置截图](../images/witcher3_mfg_6x_setup.png)仅用于辨认旧界面与路线。

## 异环

推荐 `winmm.dll`；此前反馈 `dxgi.dll` 可能触发非法模块提示。面板和 6X 曾得到用户验证，不代表全部更新版本或菜单路径均稳定。

角色、抽卡菜单卡顿有社区反馈的 NVIDIA Profile Inspector 游戏配置缓解办法；未确认它等同于菜单恢复 6X。Aurora 不自动改动全局驱动配置。[原始调查与操作说明](NTE_ZZZ_COMPATIBILITY.md)保留当时证据和限制。`Run inside the upscaler` 暂不推荐。

## 绝区零、原神与崩铁

绝区零 `11008`、组件异常和文件消失缺少可对应的版本／日志，**尚未确认修复**，也不能直接归因于 MFG 或某种拦截机制。

原神与崩铁的不同桥接、游戏版本和 FG 路线未全部验证。通用生命周期修复不等于桥接环境全部兼容。收集日志时应明确超分输入、FG 输入与 FG 输出，三者不能混为一谈。

## v1.1 的验证范围

已通过完整 Windows 构建、兼容性专项检查、运行库清单、防降级和打包校验。用户未安排新增的全面实机测试。

HUD／深度资源不匹配时会跳过可选处理；完整自动重建、GPU 提交完成及资源退役仍属后续工作。全局初始化回滚等未闭环实验已撤出本版。[发行说明](RELEASE_NOTES_AURORA_V1_1.md)列出具体范围。
